Bokuchi can export your Markdown document as a styled HTML file that you can open in any web browser, or as a PDF that anyone can view and print.

## HTML Export

The exported HTML file includes:

- **Full styling** — The rendered Markdown looks the same as in Bokuchi's preview
- **Syntax highlighting** — Code blocks retain their color highlighting
- **Image references** — Images are kept as relative paths. Place image files in the same folder structure alongside the exported HTML
- **Expanded variables** — All [variables](/guides/variables/) are replaced with their actual values
- **Math and diagrams** — KaTeX math expressions and Mermaid diagrams are rendered in the exported file
- **Alerts and emoji** — [GitHub-style alerts](/guides/markdown-basics/#alerts-callouts) keep their icons and colors, and [emoji shortcodes](/guides/markdown-basics/#emoji-shortcodes) are converted
- **Your preview font** — If you've chosen a [preview font](/guides/settings/#choosing-fonts) in Settings, the exported file uses it too. Code blocks always keep a monospace font
- **Text direction** — The [text direction](/guides/settings/#preview-text-direction) you chose (Auto, Left to Right, or Right to Left) is written into the file, so a right-to-left document stays right-to-left in the browser. Code blocks stay left-to-right
- **Code block file names** — A [file name label](/guides/markdown-basics/#file-names-on-code-blocks) written as ` ```ts:src/index.ts ` appears on the code block in the exported file too

## How to Export

1. Open the file you want to export
2. Click the **download button** in the top-right corner of the preview panel
3. Choose **Export as HTML** or **Export as PDF** from the menu
4. Choose the save location and file name

The save dialog suggests a file name based on your document's name — for example, `notes.md` becomes `notes.html` or `notes.pdf`. Unsaved documents use `markdown-export` as the default name. You can always type a different name before saving.

The exported HTML file can be opened in any web browser without Bokuchi. If your document includes images, share the image files alongside the HTML in the same relative path structure.

## PDF Export

Choosing **Export as PDF** saves your document as an A4 PDF — handy for printing or sharing with people who don't use Bokuchi.

The PDF includes the same content as the HTML export: syntax-highlighted code blocks with their file name labels, expanded variables, KaTeX math, Mermaid diagrams, alerts, emoji, your chosen [preview font](/guides/settings/#choosing-fonts), and your [text direction](/guides/settings/#preview-text-direction).

While the file is being produced, a **Generating PDF…** message appears at the bottom of the window. Large documents with many images can take a few seconds. When it finishes, a **PDF exported** confirmation appears — or an error message if something went wrong.

<Aside>
PDF output always uses light colors on a white background, regardless of your current theme, so the result stays easy to read and print. Table headers always get a neutral gray tint in the PDF, even in themes where the preview shows a colored header.
</Aside>

<Aside>
Images are recompressed as they are written into the PDF, so image-heavy documents produce much smaller files than you might expect — with no loss of resolution, and transparency preserved.
</Aside>

Marp presentations have their own PDF export that saves one slide per page — see [Marp Presentations](/guides/marp/#pdf-export).

## Other Export Options

### Settings Export / Import

Export your Bokuchi settings as a JSON file, or import settings from a file. Useful for syncing your configuration across machines.

### Variable Export / Import

Export global variables as a YAML file, or import variables from a YAML file. Useful for sharing variable sets with your team.
