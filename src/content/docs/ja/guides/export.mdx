Bokuchi は Markdown ドキュメントをスタイル付き HTML ファイルとしてエクスポートできます。また、誰でも閲覧・印刷できる PDF としての書き出しにも対応しています。

## HTML エクスポート

エクスポートされた HTML ファイルには以下が含まれます：

- **スタイル付き** — Bokuchi のプレビューと同じ見た目で出力されます
- **シンタックスハイライト** — コードブロックのカラーハイライトが保持されます
- **画像の参照** — 画像は相対パスのまま出力されます。エクスポートした HTML と同じフォルダ構成で画像ファイルを配置してください
- **変数の展開** — すべての[変数](/ja/guides/variables/)が実際の値に置き換えられます
- **数式と図表** — KaTeX の数式と Mermaid の図表がレンダリングされた状態で出力されます
- **アラートと絵文字** — [GitHub 形式のアラート](/ja/guides/markdown-basics/#アラート注意書き)はアイコンや色がそのまま残り、[絵文字ショートコード](/ja/guides/markdown-basics/#絵文字ショートコード)は絵文字に変換されます
- **プレビューのフォント** — 設定で[プレビューのフォント](/ja/guides/settings/#フォントを選ぶ)を選んでいる場合、エクスポートにも適用されます。コードブロックは常に等幅フォントのままです

## エクスポートの手順

1. エクスポートしたいファイルを開きます
2. プレビューパネル右上の**ダウンロードボタン**をクリックします
3. メニューから **HTMLでエクスポート** または **PDFでエクスポート** を選びます
4. 保存場所とファイル名を選びます

保存ダイアログには、ドキュメント名に基づいたファイル名が提案されます。たとえば `notes.md` なら `notes.html` や `notes.pdf` になります。未保存のドキュメントでは `markdown-export` が既定の名前になります。保存前に別の名前へ変更することもできます。

</Aside>

## PDF エクスポート

**PDFでエクスポート** を選ぶと、ドキュメントが A4 サイズの PDF として保存されます。印刷したいときや、Bokuchi を使っていない人に渡したいときに便利です。

PDF には HTML エクスポートと同じ内容が含まれます。シンタックスハイライト付きのコードブロック、展開済みの変数、KaTeX の数式、Mermaid の図表、アラート、絵文字がそのまま出力されます。選択した[プレビューのフォント](/ja/guides/settings/#フォントを選ぶ)も適用されます。

生成中はウィンドウ下部に **PDFを生成中…** というメッセージが表示されます。画像の多い大きなドキュメントでは数秒かかることがあります。完了すると **PDFをエクスポートしました** と表示されます。問題があった場合はエラーメッセージが表示されます。

<Aside>
PDF は現在のテーマに関わらず、常に白背景の明るい配色で出力されます。読みやすく、印刷にも適した仕上がりになります。
</Aside>

<Aside>
画像は PDF に書き込む際に再圧縮されるため、画像の多いドキュメントでも想像よりずっと小さなファイルになります。解像度は落ちず、透過も保持されます。
</Aside>

Marp プレゼンテーションには専用の PDF エクスポートがあり、1 ページに 1 スライドずつ保存されます。詳しくは [Marp プレゼンテーション](/ja/guides/marp/#pdf-エクスポート)をご覧ください。

## その他のエクスポート

### 設定のエクスポート / インポート

Bokuchi の設定を JSON ファイルとしてエクスポートしたり、ファイルからインポートしたりできます。設定の複数マシン間での同期やバックアップに便利です。

### 変数のエクスポート / インポート

グローバル変数を YAML ファイルとしてエクスポート、またはインポートできます。チームでの変数共有に便利です。
